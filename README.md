# কাফেলা ট্যুরস এন্ড ট্রাভেলস — Next.js + Supabase ওয়েবসাইট

আপনার আগের HTML ওয়েবসাইটটি এখন সম্পূর্ণভাবে **Next.js (App Router) + React + Tailwind CSS + Supabase**
দিয়ে তৈরি করা হয়েছে। এখন আপনি অ্যাডমিন প্যানেল থেকে লগইন করে ৬টি প্যাকেজেরই (ভর্তি পরীক্ষা, দলগত
ভ্রমণ, স্কুল/কলেজ শিক্ষা সফর, পারিবারিক ভ্রমণ, কর্পোরেট প্যাকেজ, কাস্টম ট্যুর) তথ্য যোগ/এডিট/ডিলিট
করতে পারবেন — প্রতিটি প্যাকেজে ছবি, এবং পিকআপ তারিখ ও সময়ও যোগ করা যাবে। পরিবর্তন সাথে সাথে
ওয়েবসাইটে সবাই দেখতে পাবে।

> **আগে থেকেই Supabase সেটআপ করা আছে?** ২টা জিনিসের জন্য ছোট আপডেট লাগবে — (১) নতুন সংযোজন (সব
> প্যাকেজে ছবি + পিকআপ তারিখ/সময়), এবং (২) **একটা গুরুত্বপূর্ণ নিরাপত্তা আপডেট** যা শুধু আপনার
> নির্দিষ্ট অ্যাডমিন অ্যাকাউন্টকেই এডিট করার অনুমতি দেয় (আগে যেকোনো লগইন করা Supabase ইউজার এডিট
> করতে পারতো, যেটা নিরাপদ ছিল না)। নিচের **"ইতিমধ্যে ব্যবহার করছেন?"** অংশটা দেখুন, পুরো ধাপ ১-৪ আবার
> করার দরকার নেই।

## এতে যা যা আছে

- `src/app/*` — পাবলিক পেজ (হোম, প্যাকেজসমূহ, প্রতিটি প্যাকেজের ডিটেইল পেজ, ফিচার, আমাদের সম্পর্কে)
- `src/app/admin/*` — অ্যাডমিন লগইন, ড্যাশবোর্ড ও প্রতিটি প্যাকেজের জন্য আলাদা এডিট পেজ
- `src/lib/supabase/*` — Supabase ক্লায়েন্ট (browser, server, middleware)
- `middleware.ts` — `/admin` এর যেকোনো পেজ লগইন ছাড়া খোলা যাবে না, স্বয়ংক্রিয়ভাবে লগইন পেজে পাঠিয়ে দেয়
- `supabase/schema.sql` — ডাটাবেস টেবিল, নিরাপত্তা নিয়ম (RLS) ও ছবি রাখার storage bucket তৈরির স্ক্রিপ্ট

## ইতিমধ্যে ব্যবহার করছেন? শুধু এই মাইগ্রেশনটা চালান

যদি আপনি আগেই Supabase প্রজেক্ট বানিয়ে সাইট চালু করে থাকেন, তাহলে নতুন ফাইলগুলো বসানোর পর নিচের
ধাপগুলো **Supabase → SQL Editor → New query**-তে একে একে চালান — এতে আপনার পুরনো কোনো ডাটা মুছে
যাবে না।

**১. নতুন কলাম যোগ করুন (ছবি + পিকআপ তারিখ/সময়):**
```sql
alter table public.packages add column if not exists pickup_date date;
alter table public.packages add column if not exists pickup_time time;
```

**২. নিরাপত্তা আপডেট চালান:** `supabase/schema.sql` ফাইলের ভেতরে `/* ... */` দিয়ে কমেন্ট করা
"SECURITY UPGRADE" ব্লকটা খুঁজে বের করুন, শুধু ওই ব্লকের ভেতরের কোডটুকু (কমেন্ট চিহ্ন `/*` `*/` বাদে)
কপি করে রান করুন। এতে একটা `admins` টেবিল তৈরি হবে এবং এডিট/ডিলিট করার অনুমতি শুধু ওই টেবিলে থাকা
ইউজারদের জন্য সীমাবদ্ধ হয়ে যাবে।

**৩. নিজেকে অ্যাডমিন হিসেবে যোগ করুন (অত্যন্ত গুরুত্বপূর্ণ — এই ধাপ ছাড়া আপনি নিজেও লগইন করে কিছু
এডিট করতে পারবেন না):**
```sql
insert into public.admins (user_id)
select id from auth.users where email = 'আপনার-অ্যাডমিন-ইমেইল@example.com';
```
নিজের আসল অ্যাডমিন ইমেইল দিয়ে এটা প্রতিস্থাপন করুন — যেটা দিয়ে আপনি `/admin/login` এ লগইন করেন।

**৪. হোম পেজ ব্যানার যোগ করুন (এটা `is_admin()` এর উপর নির্ভর করে, তাই ২ নম্বর ধাপের পরে করুন):**
`supabase/schema.sql` ফাইলে "Adds the homepage banner carousel" কমেন্ট করা ব্লকটা খুঁজে বের করুন, ওই
ব্লকের ভেতরের কোডটুকু কপি করে রান করুন। এতে হোম পেজের হেডারের নিচে অ্যাডমিন-নিয়ন্ত্রিত স্লাইডশো
ব্যানারের জন্য প্রয়োজনীয় টেবিল ও স্টোরেজ বাকেট তৈরি হবে।

এরপর ৭ নম্বর ধাপে চলে যান (নতুন কোড ডিপ্লয় করুন)। প্রথমবার সেটআপ করছেন এমন হলে নিচের ধাপ ১ থেকে
শুরু করুন — `schema.sql` চালালে এই সবকিছুই এমনিতে হয়ে যাবে, শুধু ধাপ ৩.৫ (নিচে) আলাদাভাবে করতে হবে।

## ধাপ ১: Supabase প্রজেক্ট তৈরি করুন

1. https://supabase.com এ যান, ফ্রি অ্যাকাউন্ট দিয়ে সাইন আপ করুন।
2. **New project** ক্লিক করুন, একটা নাম দিন (যেমন `kafela-tours`), একটা ডাটাবেস পাসওয়ার্ড সেট করুন,
   কাছের রিজিওন (যেমন Singapore) বেছে **Create new project** করুন। তৈরি হতে ১-২ মিনিট লাগবে।

## ধাপ ২: ডাটাবেস টেবিল তৈরি করুন

1. বাম মেনু থেকে **SQL Editor** এ যান, **New query** ক্লিক করুন।
2. এই প্রজেক্টের `supabase/schema.sql` ফাইলের সম্পূর্ণ কনটেন্ট কপি করে পেস্ট করুন এবং **Run** চাপুন।
   এতে `packages` নামে একটা টেবিল, নিরাপত্তা নিয়ম (সবাই পড়তে পারবে, শুধু লগইন করা অ্যাডমিন
   যোগ/এডিট/ডিলিট করতে পারবে), এবং ছবি রাখার জন্য `package-images` নামে একটা storage bucket তৈরি
   হয়ে যাবে।

## ধাপ ৩: অ্যাডমিন লগইন একাউন্ট তৈরি করুন

1. বাম মেনু থেকে **Authentication → Users** এ যান।
2. **Add user → Create new user** ক্লিক করুন, আপনার ইমেইল ও একটা শক্তিশালী পাসওয়ার্ড দিন।
   **Auto Confirm User** অপশনটা টিক দিয়ে রাখুন।
3. এটাই হবে `/admin/login` এ লগইন করার ইমেইল/পাসওয়ার্ড। সাইটে কোনো সাইনআপ ফর্ম রাখা হয়নি — শুধু
   আপনি নিজে Supabase ড্যাশবোর্ড থেকে অ্যাডমিন অ্যাকাউন্ট বানাতে পারবেন, তাই এটা নিরাপদ।

## ধাপ ৩.৫: নিজেকে অ্যাডমিন হিসেবে অনুমোদন করুন (গুরুত্বপূর্ণ, বাদ দেবেন না)

শুধু Supabase-এ ইউজার তৈরি করলেই এডিট করার অনুমতি পাওয়া যায় না — এটা ইচ্ছাকৃতভাবে এমন রাখা হয়েছে
যাতে কেউ যদি অন্যভাবে (যেমন সরাসরি API দিয়ে) একটা নতুন একাউন্ট বানিয়েও ফেলে, তাও সে আপনার ডাটা
এডিট করতে না পারে। **SQL Editor → New query**-তে গিয়ে এটা রান করুন:

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'আপনার-অ্যাডমিন-ইমেইল@example.com';
```

উপরের ইমেইলটা ধাপ ৩-এ যে ইমেইল দিয়ে অ্যাকাউন্ট বানিয়েছেন সেটা দিয়ে প্রতিস্থাপন করুন। একাধিক অ্যাডমিন
লাগলে, প্রতিটা অ্যাডমিনের জন্য আগে ধাপ ৩ (Authentication → Users এ নতুন ইউজার তৈরি) করুন, তারপর
এখানে তাদের ইমেইল দিয়ে এই SQL আবার রান করুন — প্রতিটা অ্যাডমিনের জন্য আলাদাভাবে।

**অতিরিক্ত নিরাপত্তা (ঐচ্ছিক কিন্তু সুপারিশকৃত):** Supabase ড্যাশবোর্ডে **Authentication → Sign In / Providers
→ Email** এ গিয়ে "Allow new users to sign up" অপশনটা বন্ধ করে দিন। এতে কেউ ওয়েবসাইট এড়িয়ে সরাসরি
নতুন একাউন্ট বানাতেই পারবে না — উপরের `admins` টেবিলের সাথে মিলিয়ে এটা দুই স্তরের সুরক্ষা দেয়।

## ধাপ ৪: API কি (keys) কপি করুন

1. **Project Settings (⚙️) → API** এ যান।
2. **Project URL** এবং **anon public** কি — এই দুটো কপি করুন।
3. প্রজেক্টের রুটে থাকা `.env.local.example` ফাইলটাকে `.env.local` নামে কপি করুন এবং ভ্যালু দুটো
   বসিয়ে দিন:

   ```
   NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
   ```

## ধাপ ৫: লোকালি রান করুন

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে http://localhost:3000 খুলুন। অ্যাডমিন প্যানেল: http://localhost:3000/admin/login

## ধাপ ৬: ডিপ্লয় করুন (Vercel সবচেয়ে সহজ, Netlify-ও চলবে)

**Netlify দিয়ে ডিপ্লয় করুন:**
1. এই কোডটা একটা GitHub রিপোজিটরিতে পুশ করুন (`netlify.toml` ফাইলটা প্রজেক্টের রুটেই আছে, তাই
   Netlify বিল্ড কমান্ড ও Next.js প্লাগিন নিজে থেকেই ঠিকভাবে সেট হয়ে যাবে)।
2. https://app.netlify.com এ গিয়ে **Add new site → Import an existing project** করে
   রিপোজিটরিটা বেছে নিন। Build command ও publish directory `netlify.toml` থেকেই আসবে, কিছু বদলানোর
   দরকার নেই।
3. **Site configuration → Environment variables** এ গিয়ে দুটো ভ্যারিয়েবল যোগ করুন:
   `NEXT_PUBLIC_SUPABASE_URL` ও `NEXT_PUBLIC_SUPABASE_ANON_KEY` (ধাপ ৪ থেকে যা পেয়েছিলেন)।
4. **Deploy site** চাপুন। প্রথমবার Netlify স্বয়ংক্রিয়ভাবে `@netlify/plugin-nextjs` ইনস্টল করে নেবে।
5. ডিপ্লয় হয়ে গেলে সাইট লিংকে গিয়ে `/admin/login` এ লগইন করে ৬টি প্যাকেজেই প্রয়োজনীয় তথ্য একে একে
   যোগ করুন — কোনো ডাটা আগে থেকে ভরা থাকবে না, সম্পূর্ণ খালি অবস্থায় শুরু হবে।

**Vercel দিয়ে (বিকল্প):**
1. রিপোজিটরি GitHub-এ পুশ করে https://vercel.com এ **Add New → Project** করে import করুন।
2. একই দুটো Environment Variable যোগ করে **Deploy** চাপুন।

## ব্যবহার

- **অ্যাডমিন লগইন:** `yourdomain.com/admin/login`
- **ড্যাশবোর্ড:** লগইন করার পর ৬টি প্যাকেজের কার্ড দেখতে পাবেন, প্রতিটাতে কতগুলো আইটেম আছে তা
  দেখাবে। যেকোনো একটাতে ক্লিক করলে সেই প্যাকেজের এডিট পেজ খুলবে।
- **যোগ করুন:** নাম, লোকেশন, খরচ, বিবরণ, ছবি, এবং পিকআপ তারিখ ও সময় দিয়ে ফর্ম পূরণ করে **যোগ করুন**
  চাপুন। খরচ খালি রাখলে ওয়েবসাইটে "যোগাযোগ করুন" দেখাবে, আর পিকআপ তারিখ/সময় খালি রাখলে ওয়েবসাইটে
  সেটা দেখানো হবে না।
- **এডিট:** তালিকায় যেকোনো আইটেমের পাশে **এডিট** বাটনে চাপুন, ফর্মে ডাটা লোড হবে, পরিবর্তন করে
  **আপডেট করুন** চাপুন।
- **ছবি পরিবর্তন:** এডিট করার সময় নতুন ছবি বেছে নিলে পুরনো ছবির জায়গায় নতুন ছবি বসে যাবে। ছবি না
  বদলালে আগের ছবিই থেকে যাবে।
- **ডিলিট:** **ডিলিট** বাটনে চাপুন, কনফার্ম করলে মুছে যাবে (এটা ফিরিয়ে নেওয়া যায় না)।
- **ক্রম নম্বর:** ওয়েবসাইটে কোনটা আগে দেখাবে তা নিয়ন্ত্রণ করতে চাইলে ছোট সংখ্যা ব্যবহার করুন
  (ঐচ্ছিক, খালি রাখলে ০ ধরা হবে)।
- **লগ আউট:** উপরে ডান পাশে বাটন আছে।

## ছবি ও পিকআপ তারিখ/সময়

৬টি প্যাকেজেই (ভর্তি পরীক্ষা প্যাকেজ সহ) নাম, লোকেশন, খরচ, বিবরণ, একটা ছবি, এবং ঐচ্ছিক পিকআপ
তারিখ ও সময় যোগ করার সুবিধা আছে। পিকআপ তারিখ/সময় দেওয়া থাকলে সেটা ওয়েবসাইটে ঘড়ির আইকনসহ কার্ডে
দেখানো হবে; খালি রাখলে সেই অংশটুকু ওয়েবসাইটে দেখানো হবে না।

## হোম পেজ ব্যানার

`/admin/dashboard` থেকে "হোম পেজ ব্যানার" এ ক্লিক করে, বা সরাসরি `/admin/banners` এ গিয়ে হোম পেজের
হেডারের ঠিক নিচে দেখানো স্লাইডশো ব্যানার পরিচালনা করতে পারবেন। প্রতিটা ব্যানারে একটা ছবি (আবশ্যক),
একটা লিংক (ঐচ্ছিক — ক্লিক করলে কোথায় যাবে), একটা টাইটেল (শুধু নিজের রেফারেন্সের জন্য, ওয়েবসাইটে
দেখানো হয় না), এবং একটা ক্রম নম্বর যোগ করা যায়। একাধিক ব্যানার থাকলে সেগুলো অটোমেটিক পালাক্রমে
ঘুরতে থাকবে, সাথে ম্যানুয়াল তীর বাটন ও ডট নেভিগেশনও থাকবে। কোনো ব্যানার যোগ না করা পর্যন্ত এই
অংশটুকু ওয়েবসাইটে দেখানো হবে না — সাইট আগের মতোই স্বাভাবিক দেখাবে।

## নতুন করে ২৬টি বিশ্ববিদ্যালয়ের পুরনো তালিকা যোগ করতে চান?

`supabase/schema.sql` ফাইলের একদম নিচে একটা কমেন্ট করা (`/* ... */`) `insert into` স্টেটমেন্ট আছে।
সেটার কমেন্ট মার্ক তুলে Supabase SQL Editor-এ রান করলে সরাসরি ডাটাবেসে ঢুকে যাবে — এরপর অ্যাডমিন
প্যানেল থেকে এডিট/এড/ডিলিট করতে পারবেন। (ইচ্ছা করলে অ্যাডমিন প্যানেল থেকে হাতেও একে একে যোগ করতে
পারেন।)

## গঠন সংক্ষেপে (কারিগরি নোট)

- সব ডাটা একটাই টেবিল `packages` এ থাকে, `category` কলাম দিয়ে বোঝা যায় কোন প্যাকেজের — এতে ভবিষ্যতে
  নতুন প্যাকেজ যোগ করাও সহজ (শুধু `src/lib/categories.ts` ফাইলে একটা এন্ট্রি যোগ করলেই হবে)।
- পাবলিক পেজগুলো সবসময় Supabase থেকে সরাসরি সর্বশেষ ডাটা লোড করে (কোনো ক্যাশ নেই), তাই অ্যাডমিন
  পরিবর্তন করার সাথে সাথেই ওয়েবসাইটে দেখা যাবে।
- ছবি Supabase Storage-এর `package-images` bucket-এ পাবলিকভাবে সংরক্ষিত হয়।
- `middleware.ts` প্রতিটা `/admin/*` রিকোয়েস্টে চেক করে ইউজার লগইন করা আছে কিনা; না থাকলে
  `/admin/login` এ পাঠিয়ে দেয়।
